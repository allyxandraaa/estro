# 🌸 Estro

Українськомовний веб-застосунок для відстеження менструального циклу та жіночого здоров'я.

## Про проєкт

Більшість популярних трекерів циклу або повністю англомовні, або мають неякісну локалізацію — і майже всі виконують роль простого календаря без аналізу симптомів. Estro вирішує цю проблему: користувачка веде щоденник циклу та симптомів, а система аналізує записи з часом і повідомляє про нетипові паттерни, які можуть свідчити про проблеми зі здоров'ям.

## Функціональність MVP

- **Реєстрація та авторизація** — email + пароль
- **Профіль** — індивідуальні параметри циклу
- **Календар циклу** — фази та прогноз наступної менструації
- **Щоденне логування симптомів** — біль, настрій, кровотеча, втома, нотатки
- **Відстеження затримки** — повідомлення та підрахунок днів
- **Аналіз паттернів** — попередження при нерегулярному циклі та аномальних симптомах, графік симптомів відносно фаз
