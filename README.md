# Estro

Українськомовний веб-застосунок для відстеження менструального циклу та жіночого здоров'я.

Дозволяє відмічати менструації на інтерактивному таймлайні, бачити поточну фазу циклу й прогноз наступних подій, вести щоденник симптомів та отримувати сповіщення про наближення менструації або овуляції, а також про затримку. Дані можна експортувати в PDF.

## Сторінки

| Сторінка | Що можна робити |
|----------|----------------|
| **Календар** | Прокручувати таймлайн днів, відмічати початок і кінець менструації, бачити поточну фазу (менструальна, фолікулярна, овуляція, лютеальна, затримка), отримувати сповіщення |
| **Щоденник симптомів** | Записувати кровотечу, базальну температуру, біль, стрес, травлення, апетит, виділення та нотатки для будь-якого дня |
| **Профіль** | Переглядати середню тривалість циклу та менструації, змінювати ім'я і пошту, завантажувати PDF-звіт за річний період |

## Запуск через Docker

### Що потрібно

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- Репозиторій клонований локально

### 1. Запусти

```bash
docker compose --profile prod up --build
```

Перший запуск займе кілька хвилин (збірка образів). Наступні запуски — швидші.

### 2. Відкрий у браузері

- Застосунок: http://localhost:5173
- Документація API: http://localhost:3000/docs

### Зупинка

```bash
# зупинити контейнери
docker compose down

# зупинити і видалити базу даних (скидає всі дані)
docker compose down -v
```
